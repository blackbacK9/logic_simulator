# 使い方ガイド

現在PCのみの対応となっております.
タブレットやスマートフォンに関しては開けますが, ほぼ機能しません.
よって現在鋭意開発中になります.
ご了承ください.

## 画面ガイド

### 画面左側
論理ゲートやスイッチ, LEDなどがおかれています.

### 画面上部
- 保存ボタン: 現在キャンバス上に存在する回路をJSONファイルに保存し, 端末のローカルに落とすことができます.
- 開く: 過去にローカルに落としたJSONファイルを開くことができます.
- 回路リセット: キャンバス上に存在する回路をリセットして, 初期の状態に戻すことができます.
- 真理値表: スイッチ(ボタン)とLED回路が画面上に存在し, 二つの素子がつながっている際に回路の真理値を表示することできます.
- モジュール登録: キャンバス上に存在する回路を一つのパッケージとして登録することができます.
モジュール登録は現在バグが頻出中です。またサイトを再読み込みするとパッケージは消えてしまいます.
- [-] ボタン: キャンバスのサイズを縮小します.
- [+] ボタン: キャンバスのサイズを拡大します.
- リセット: キャンバスのサイズをリセットします. (初期状態が100%)

### 画面下部
キャンバス上に存在する回路の波形を見ることができるツールです.
これについても不自然な挙動をすることがありますので, 信用しないことをおすすめします.

## 操作ガイド
 キャンバス上の何もないところをマウスでドラッグすると移動することができます.

マウスでオブジェクトを選択すると対象を移動することができます.

選択したオブジェクトはDeleteキーを押すことによって削除することができます.

Ctrl + 左クリックでオブジェクトの複数選択ができます.

Ctrl + 左ドラッグで範囲選択ができます.
